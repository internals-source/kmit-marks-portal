Students falling below the qualifying marks in Theory or Lab, in either MID — flagged individually per JNTUH/KMIT re-registration rules.

Re-Registration Candidates

Checks each MID's Theory and Lab marks independently against the qualifying marks you set below. If a student falls short in any single one — I MID Theory, II MID Theory, I MID Lab, or II MID Lab (whichever apply to that subject) — they're flagged for re-registration, per JNTUH/KMIT rules. A student is only evaluated once every applicable offering for that subject has marks entered — anything missing is listed separately as Incomplete instead of being guessed at.
Set the qualifying total per your regulation (KR24 theory internal is out of 40 — 15 descriptive + 5 Part-C + 10 assignment + 10 objective — so the standard flag is below 14 of 40, i.e. 35%) — this tool doesn't assume a fixed denominator since it can vary by subject/regulation.

Add / Update Mark Structure Column

CSV columns: regulation, year, type, column_key, column_label, max_marks, sort_order, auto_calculated, formula, calc_type, calc_config — the sample mirrors the real KR24/II/theory structure for theory (with working calc_type/calc_config), plus bare skeletons for lab and mandatory (each year's real structure differs, so rename/add/remove rows and adjust max_marks as needed before uploading). regulation/year/type can be left blank per row to fall back to the dropdowns above. sort_order can be left blank to auto-number rows (numbering restarts for each regulation/year/type group, in file order), auto_calculated is true/false. formula is a human-readable note only — for a column to actually compute, set calc_type to sum (with calc_config like {"columns":["a","b"]}) or best_n_of_pairs (with {"pairs":[["1a","1b"],["2a","2b"]],"n":1}).
